# Security policy

TruckSOS is a live application with real users. If you believe you have found a
security vulnerability, please report it privately instead of opening a public issue.

- Email: **trucksos.support@gmail.com**
- Please include steps to reproduce and the affected component (app, web, database/API).

You will get an acknowledgement as soon as possible, and a fix will be prioritised
based on severity. Please do not access, modify, or delete data that is not yours
while testing.

## Scope

- Mobile apps (`com.andeaf.trucksos` on Android and iOS)
- Web app at https://trucksos.net
- Supabase backend (database policies, RPC functions, storage, edge functions)

## Out of scope

- Denial-of-service or volumetric attacks
- Issues in third-party services (Supabase, Expo, Google, Apple, Brevo, Cloudflare)
- Social engineering of users or staff
